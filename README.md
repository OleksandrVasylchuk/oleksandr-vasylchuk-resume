# Oleksandr Vasylchuk — Portfolio

Personal portfolio and downloadable CV of **Oleksandr Vasylchuk**, Senior Full-Stack WordPress Developer & Tech Lead.

- **Live:** https://oleksandr-vasylchuk.vercel.app
- **CV (PDF, ATS-friendly):** https://oleksandr-vasylchuk.vercel.app/Oleksandr_Vasylchuk_CV.pdf

## Stack

React 19 · TypeScript · Vite · Three.js (`@react-three/fiber`, `@react-three/drei`) · Motion · Lenis · pdfkit

## Single source of truth

All content lives in [`src/data/resume.json`](src/data/resume.json). The website **and** the PDF are generated from it,
so editing one file updates both.

## Scripts

```bash
npm install
npm run dev          # local dev server
npm run resume:pdf   # regenerate public/Oleksandr_Vasylchuk_CV.pdf
npm run og           # regenerate public/og.png (social preview, needs local Chrome)
npm run shots        # re-shoot project screenshots (needs local Chrome)
npm run build        # pdf + type-check + production build (dist/)
npm run preview      # preview the production build
```

`npm run build` runs `resume:pdf` automatically (via `prebuild`), so Vercel always ships a fresh PDF.
`og` and `shots` need a local Chrome, so their output (`public/og.png`, `public/projects/*.jpg`) is
committed and regenerated by hand when the content changes.

## Deploy

The project is deployed on Vercel. `vercel --prod` from the repo root, or push to `main` if the Git integration is connected.
